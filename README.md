# Big Head Mode 🤪

Turn your friend's face into a ridiculous looping GIF — right in the browser.

1. Upload a photo and fit their face in the oval (drag, pinch or zoom, tilt, and set the eye line).
2. Pick one of 16 animations: Bobblehead, Deal With It, Spin Cycle, Dramatic Zoom, Disco Bounce, Face Rain, Full Rage, Jelly Wobble, Blast Off, Clone Army, Party Hat, Laser Eyes, Sad Cloud, Pop Art, Peekaboo, Vibe Trail.
3. Add meme captions, pick a speed, and hit **Make the GIF**. Save or share it.

Everything runs client-side (a tiny built-in GIF encoder, no libraries). Photos never leave the device.

## Run locally

It's a single static file — open `index.html` in a browser, or:

```sh
npx serve .
```

## Deploy

Static site; deploys on Vercel with no build step (framework preset: **Other**).
